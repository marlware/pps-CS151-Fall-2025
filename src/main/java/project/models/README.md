# models

The concrete classes that make up the shop.

## Files
- `ShopTemp.java` - main driver with the console menus (main, customer, management).
- `VendorTemp.java` - vendor account: stocks products, updates prices, manages promos, holds a balance.
- `CustomerTemp.java` - customer account: balance, rentals and rental history.
- `PromoWindow.java` - a discount fraction that is active between a start and end time.
- `Labubu.java` - rentable Labubu product with a color and rarity.
- `DigiCamTemp.java` - rentable digital camera with a model, battery life and power state.

## Running
Run `ShopTemp` as a Java application and follow the console prompts (see the root README for full steps).
